## Геймплей

Игрок исследует процедурно сгенерированное подземелье, сражается со скелетами, собирает ключи для открытия запертых дверей и должен добраться до комнаты с боссом (Skeletrax) и победить его.

## Управление

| Действие | Клавиатура |
| Движение | Стрелки / WASD |
| Атака | Left Shift / J |
| Взаимодействие (открыть дверь ключом) |
| Пауза |

## Технологии и алгоритмы

- **Движок:** Unity, язык программирования — C#.
- **Генерация структуры уровня:** метод двоичного разбиения пространства (BSP-дерево) для размещения комнат.
- **Соединение комнат:** триангуляция Делоне по центрам комнат + минимальное остовное дерево (MST, алгоритм Крускала) с добавлением небольшой доли дополнительных рёбер сверх остова для альтернативных путей.

## Структура проекта

- `Assets/Scripts/Map` — генерация уровня (BSP, триангуляция, MST, прокладка коридоров) и наполнение подземелья.
- `Assets/Scripts/Player Scripts` — движение, атака и характеристики игрока.
- `Assets/Scripts/Enemy Scripts` — ИИ противников и босса.
- `Assets/Scripts/Objects` — интерактивные объекты (двери и т.п.).
- `Assets/Scripts/Game Components` — управление состоянием игры, меню, звук.

## Как запустить

1. Открыть проект в Unity через Unity Hub (версия указана в `ProjectSettings/ProjectVersion.txt`).
2. Открыть сцену `Assets/Scenes/Menu.unity`.
3. Нажать Play.
